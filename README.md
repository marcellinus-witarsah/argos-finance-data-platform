# argos-finance-data-platform
A market data platform for financial data

## Road Map
### Phase 1
- [ ] Ingestion (Alpha Vantage)
- [ ] Store in Iceberg
- [ ] Execute using Spark
- [ ] Manage metadata using Apache Gravitino and use Postgres as metastore backend
- [ ] Apache Superset for Displaying data

### Phase 2 (SOON)
Basic API (/btc/price)
### Phase 3 (SOON)
Indicators + /btc/signal
### Phase 4 (SOON)
Clean architecture + caching
### Phase 5 (SOON)
AI agent + public API
